# Appraisal Toolbox Native Helper

Dedicated Native Host: `com.appraisal.toolbox.helper`.

Only actions required by the eight toolbox entries are exposed. Other inherited
actions return `APPRAISAL_TOOLBOX_ACTION_NOT_ALLOWED`.

The runtime is installed under `%LOCALAPPDATA%\AppraisalToolbox`. It does not
install or require Tianyuan Workbench, Connector, MCP, or Tianyuan CLI.
