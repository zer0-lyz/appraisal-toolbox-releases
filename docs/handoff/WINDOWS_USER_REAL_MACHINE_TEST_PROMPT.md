请记录Windows版本/架构、Chrome/Edge版本、WPS或Office是否安装，标明这是新机首装、已有环境重装或升级。优先新机首装，Chrome与Edge都测试；某项无法测试写“未覆盖”。所有文件测试使用新建目录和测试副本。

不修改天源系统或其他软件；不清除原浏览器资料；不读取、记录或上传密码、验证码、Cookie、令牌、真实地图Key。阿里登录和滑块由本人手动完成，agent不得代填或绕过。截图遮盖账号和配置值。建议用新建浏览器测试Profile。

## 二、安装（必须由本人普通桌面启动）

1. 下载上述完整ZIP和SHA256SUMS.txt，先用Get-FileHash或系统校验工具核对ZIP。摘要不符立即停止。完整解压到可写普通文件夹，不在ZIP内运行。
2. 从开始菜单打开经典Windows PowerShell，在解压目录执行 .\install.cmd；也可正常双击install.cmd。如果agent协助，请让本人启动安装；agent不要通过调度任务、代理进程或修改脚本绕过上下文门禁。
3. 记录七步结果和安装退出状态。默认安装根是 %LOCALAPPDATA%\AppraisalToolbox。核对installation-report.txt的status，Native EXE存在且摘要一致。失败保留错误提示与报告，安装失败时不把后续业务写成通过。
4. 从普通桌面检查 native-helper\native_host.exe --self-test：ok:true，4技能导入通过，不人为设置Python/runtime环境覆盖变量。会核验注册表的人可只读检查Chrome/Edge×32/64四项及manifest/exe/origin；不会执行则写该子项未覆盖，不手工补键来掩盖安装失败。
5. Chrome打开chrome://extensions，Edge打开edge://extensions，开发者模式加载安装报告给出的extension目录。核对扩展ID、名称和版本，打开侧边栏，首页应显示“本机助手正常”。核验时仅记录报告范围，不把子进程读回当成所有机器通过。

## 三、四个正式业务模块（两个浏览器都尽量覆盖）

1. 浙江土地市场网：行政区加载；选择有已知成交记录的地区、用途和日期，设置新输出目录，受控抓取一次。记录条件与条数；核对Excel、HTML和history存在，Excel可打开，结果页在当前浏览器窗口新标签打开。未配置高德时顶部应提示配置；本人配置JS API Key后重新生成结果，核对地图，不能公开Key。零条结果不能代替非零字段验收。
2. 阿里司法拍卖：筛选条件→输出目录→确认参数→打开页面；本人登录/验证后抓取至少1条有效记录。导出Excel并打开，记录数与结果一致；加载历史、清空、再加载，核对结果页/Excel/地图/重抓按钮状态。当前设计抓取已加载的当前一页，不要求不存在的页数参数。
3. 阿里资产租赁：设定日期范围、页数和新输出目录，抓取已成交案例。核对每条本场成交事实与结束日期在范围内，流拍和推荐标的不混入，页数按设定执行。记录读取/有效/跳过数量，导出Excel并打开结果页。遇滑块本人手动处理；无有效成交如实写0条或未覆盖非零产物，不放宽规则。
4. 表格设置：准备含表格的无敏感内容.docx副本。测试输出副本、指定新目录、直接覆盖三模式；覆盖时先取消，源文件应不变且不执行；再确认，格式应变化。可用Get-FileHash记录前后SHA；用另一个损坏测试.docx验证错误隔离，不能影响正常文件。无WPS/Office时标记文档打开未覆盖。

首页4业务+2开发中+2辅助入口完整；安居客/折旧仅确认“开发中”分类，不作为正式可用承诺。窄面板无明显溢出，错误为中文、有复制诊断入口，不泄漏源码或完整命令。检查扩展侧边栏与后台console是否出现新错误。
