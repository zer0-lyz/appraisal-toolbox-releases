# 阿里司法拍卖与阿里资产租赁登录门禁修复

## 2026-10-10 租赁日期范围与成交金额补充

- 根因：搜索列表不提供可靠的服务端结束日期筛选，旧逻辑把整页列表候选都导航到详情，再依据详情日期过滤；用户会看到所选期间以外的记录被逐条抓取。
- 修复：卡片日期只从“结束时间/结束日期/截止时间/截止日期”字段取值，日期明确超界的记录在详情导航前跳过。卡片未提供结束日期时继续读详情，但日期范围生效时要求详情必须有可解析结束时间。只在一页所有记录都明确早于起始日时提前停页；存在未知日期就继续。
- 根因：租赁详情的已成交首年租金字段常写作“成交价”（如“成交价 43,000 元/年”），旧解析器只识别拍卖型“拍下价/当前价”，成交金额为空，真实成交案例因此被丢弃。
- 修复：明确“成交价”视为首年租金成交价，参与成交金额和详情就绪判断；仍要求已结束、非流拍且有成交价或正出价数，不将单纯“已结束”误判成交。
- 合成回归：复现含“发布日期 2026/09/10、结束时间 2023/12/15”的卡片，按 2026 日期范围不进入详情；复现范围内“成交价 43,000 元/年”详情，完整经过列表→详情→结果写入。真实阿里登录态和实时网络抓取单独列为未覆盖。

## 用户可见问题

2026-10-09 的司法拍卖截图中，“打开并登录”路径报阿里验证错误，随后开始抓取又报登录错误。用户无法判断是否在验证、登录，还是抓取逻辑本身失败。

## 根因

- 拍卖模块把 `login.taobao.com`、`passport.taobao.com` 和包含 `login` 的路径一并算作安全验证 URL；租赁模块也把 `login.taobao.com` 明确并入验证 URL。
- 两个模块的页面探测器使用通用 `[class*=slider]` 与 `[class*=verify]` 选择器。普通图片轮播和“已核验”徽章等页面元素也可能误报为验证码。
- 登录与验证错误在界面上附带原始 `ALIBABA_*` 错误码，且打开列表后被重定向时提示“打开失败”，没有说明标签页已打开并需要人工登录。

## 修复

- 新增 `src/core/alibaba-page-state.js`，集中识别淘宝登录域名/路由、明确的反爬验证 URL、页面文本、错误码与用户操作文案。登录域名和路径不会被报告为验证页。
- 两个模块统一使用该分类；将验证码 DOM 检测收窄到 captcha、NC、JDJRV、GeeTest 和明确的 slider-verify 标记，移除普通 `slider` / `verify` 类名匹配。
- 拍卖页面状态同步函数单独实现同一优先级，因为 Chrome `scripting.executeScript` 会序列化函数，不能引用模块外闭包。
- 打开源页后识别重定向状态；登录与验证提示告知页面已在当前标签打开，要求用户手动处理后回到工具箱重试。抓取错误不再把内部错误码直接展示给用户。
- 不自动登录、不读取密码或令牌、不处理或绕过验证码。

## Windows 回归

- `windows/tests/alibaba-module-regression.mjs`：7 组页面分类、Passport 登录门禁、拍卖状态同步、错误文案和 DOM 选择器检查通过。
- `windows/tests/frontend-gates-fix2.cjs`：拍卖、租赁及其他既有模块的前置条件组件检查通过。
- `windows/tests/alibaba-native-regression.cjs`：两模块用合成案例生成 HTML、历史文件与 Excel，使用便携 Python 回读工作表与示例行通过。
- `native_host.exe --self-test`：通过，四个 Python 技能导入烟测均为成功。
- 上述均不代表真实阿里登录态/网络结果通过。真实页面验收仍需在 Chrome/Edge 当前标签页手动完成登录或验证，并观察实际抓取结果。

## macOS 携带要求

拍卖和租赁共用 `src/core/alibaba-page-state.js`；macOS 分支应携带此模块及两处调用，不得回退到通用 slider/verify CSS 选择器。将登录域名、Passport 路由、challenge URL、正常列表 URL 和误报 DOM 标记加入 macOS 自动回归。真实验证码必须继续由用户手动完成。

## 2026-10-10 Windows 安装回归补充

- 对完整候选包执行隔离安装时发现，`Copy-Tree` 将 `Get-ChildItem` 输出直接传给 `Copy-Item`；python-docx 中名为 `[Content_Types].xml` 的真实文件被 PowerShell 当成通配符字符类，导致安装在暂存阶段回滚。
- Windows 安装器现递归枚举字面路径，并以 .NET `System.IO.File.Copy` 复制文件；安装回归明确比较包内和安装后该模板文件的 SHA-256。
- Native Helper、Python、阿里模块业务代码均未因该安装器修复而改变；Native EXE复用已验证版本。重新安装仍需通过包内 `SHA256SUMS` 与逐键独立注册表核验。
