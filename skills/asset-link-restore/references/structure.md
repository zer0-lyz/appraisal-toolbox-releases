# 资产基础法评估明细表「表结构规律与链接恢复要点」

> 适用：天源资产评估执业系统导出的资产基础法评估明细表（表1~表6 模板），约 90 张 sheet。

## 一、四层汇总链条（按 sheet 名称编号组织）

| 层级 | sheet 命名规律 | 示例 | 说明 |
|---|---|---|---|
| 叶子明细表 | `N-M` 或 `N-M-K`（名不含"汇总"） | `3-1-1现金`、`4-4股权投资` | 最底层逐行明细，表尾有"合计"行 |
| 二级汇总表 | `N-M` + 含"汇总"字样 | `3-1货币资金汇总表`、`4-8固定资产汇总` | 行内编号 `N-M-K`，行值=叶子表合计 |
| 分类汇总表 | `N-流动资产汇总` / `N-非流动资产汇总` / `N-流动负债汇总` / `N-非流动负债汇总` | `3-流动资产汇总`、`4-非流动资产汇总` | 行内编号 `N-M`，行值=二级汇总合计（或叶子合计） |
| 分类汇总 | `2-分类汇总` | — | 行值=分类汇总表对应行 |
| 总汇总表 | `1-汇总表`（金额单位：人民币**万元**） | — | 行值=2-分类汇总对应行 ÷ 10000 |

链接链条：`叶子表合计行 → 二级汇总表行 → 分类汇总表行 → 2-分类汇总行 → 1-汇总表行(÷10000)`

## 二、列结构规律

- 表头通常在 R5（部分在 R6），子表头在 R6/R7；数据行不固定从 R7 开始
  （`3-2交易性金融资产汇总`、`3-9存货汇总` 数据从 R6 开始，无子表头行）。
- `账面价值` / `评估价值` 列用表头文字定位（R4~R8 行扫描）。
- 表尾"合 计"行：A 列含"合计"字样（**中间可能有全角/半角空格**，匹配前须去空格）。
- 减值结构：`合计(毛) → 减：减值准备/坏账准备 → 合计(净)`，**向上链接取最后一个"合计"行（净值）**。

## 二·A 合计行定位：内容识别，绝不依赖固定行号（重要设计原则）

**科目表（叶子表）数据条数不确定**：同一模板各表明细行从 1 行到 300+ 行不等，
且评估人员后续增删行是常态（合计行位置必然漂移）。因此：

1. 叶子表合计行 = **A 列（去空格后）含"合计"的最后一行**——按内容动态定位；
2. 汇总表合计行位置**相对固定**（模板约定），但脚本仍按内容检测
   （B/C 列含"合计"，如 `3-9存货汇总` C23=合 计），以兼容表内微调；
3. 已验证：真实文件（10~309 行不等的表）与"插入 3 行数据后合计行下移"的测试文件，
   均能正确定位到新合计行并生成正确链接（如 `3-1货币资金汇总表!D7 = ='3-1-1现金'!F29`）；
4. 数据行识别用编号正则（叶子表 `^\d+$`，汇总表 `^\d+-\d+(-\d+)?$`），
   不做任何"从第 X 行开始"的假设；
5. 若某叶子表有数据行但找不到"合计"行，脚本输出 `[警告]` 提示人工检查（不静默漏链）。

**源公式无缓存值（None）的处理**：openpyxl 重建/粘贴过的文件，公式单元格可能无缓存值，
此时对比结果标记为"源无缓存值（以 Excel 实算为准）"，不误报为"不一致"。

## 三、原值/净值双列特殊结构（向上汇总取"净值"）

| 表 | 列结构 | 向上汇总取值 |
|---|---|---|
| 固定资产类 `4-8-1..4-8-6` | K账面原值 L账面净值 M评估原值 N成新率% O评估净值 | 原值/净值双列并存，父表 `4-8固定资产汇总` 已有链接，勿动 |
| `4-8固定资产汇总` | D账面原值 E账面净值 F评估原值 G评估净值 | 分类汇总行取 **E/G（净值）** |
| `4-7-1投资性房地产`(成本) | L原值 M净值 N评估原值 O成新率 P评估净值 | 取 **M/P（净值）** |
| `4-7-3投资性地产`(成本) | L原始入账价值 M账面原值 N账面净值 O评估价值 P增值额 | 取 **N/O（账面净值/评估价值）** |
| `4-9-2在建（设备）` | H设备费 I资金成本 J安装费 K合计 / L..O 评估 | 取 **K/O（合计子列）** |
| `4-10生产性生物资产` | G原值 H净值 I评估原值 J成新率 K评估净值 | 取 **H/K（净值）** |

## 四、关键坑位清单

1. `合计` 匹配必须先去空格（模板写的是 `合     计`）。
2. 固定资产/投资性房地产/在建设备/生物资产/油气资产汇总取**净值列**，不是原值。
3. 减值结构（毛合计→减减值→净合计）链接取**最后一个合计行**。
4. 数据行识别用编号正则（叶子表 `^\d+$`，汇总表 `^\d+-\d+(-\d+)?$`），不要假设固定起始行。
5. 万元换算只发生在 `1-汇总表`（D/E 都是 ÷10000）；`1-汇总表` 末行还有**净资产行**（=资产总计−负债合计），勿遗漏。
6. 跨表公式一律 `='表名'!单元格`（含中文/数字/`-` 的表名必须加单引号）。
7. 原增值率是保留 2 位小数的静态值（如 1.89），恢复公式后计算值 1.8942，对比容差取 ±0.01 个百分点。
8. 已存在的公式（如 `4-8固定资产汇总` 的跨表链接、SUBTOTAL 小计、`1-汇总表` D34/E34 勾稽校验）一律**不动**。
9. `00000000` 表为旧版 Excel 宏病毒残留文本页（1998 XF.Classic），非评估数据，保持隐藏并建议删除。
10. `formulas` 库不支持 `SUBTOTAL`（`4-8固定资产汇总` 相关行会报 #NAME?），属引擎限制而非文件错误，Excel/WPS 中正常。
11. **合并三列结构**：部分表（`3-9-x` 存货系列及 pandas 导出表）"账面价值/评估价值"为合并单元格跨
    `数量/单价/金额` 三列，R5 定位到的是合并区左上角（数量列），金额列在 R6 子表头"金额"处。
    脚本已自动用 R6"金额"列覆盖 bk/ev（如 `3-9-2原材料` 取 G/J 而非 E/H）；单列金额结构表不受影响。
    若遇金额列在非 R6 位置的特殊表，需在 `LEAF_COL_OVERRIDE` 显式指定。
12. **净资产为负的增值率符号**：增值率公式用 `ABS()` 分母（`=IF(C=0,"",E/ABS(C)*100)`），
    账面净资产为负（资不抵债）时增值率显示正值（与原系统静态值一致）；正常科目（账面>0）不受影响。
13. **`4-7-3投资性地产`(成本模式土地) 列结构**：L=原始入账价值 M=账面原值 N=账面净值 O=评估价值
    P=增值额。向上汇总取 **N/O**（账面净值/评估价值），勿取 L（原始入账价值）。
14. **原模板留空的列保持留空**：`put()` 对原静态值为空的列不写入公式。如 `4-8固定资产汇总` 中
    `4-8-7固定资产清理` 无账面原值/评估原值概念（原模板 D/F 列为空），仅恢复净值列 E/G；
    强行链接会把叶子表"账面价值"误挂到"账面原值"列。
