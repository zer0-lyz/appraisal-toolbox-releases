# 资产基础法明细表 汇总链接恢复

## Overview

把评估明细表中"被粘贴成静态数值、丢失跨表引用"的汇总数，恢复为可追踪的四层公式链接，
并验证恢复后的计算值与原始静态值完全一致。**不修改任何金额数据，不修改表头框架，
保持原隐藏表隐藏（模板规范：用不到的表页应隐藏）**。产出：恢复后的明细表 + 对比报告。

## 工作流程

### Step 1 环境准备
- 确认 Python 3.10+ 可用；核心脚本仅依赖 `openpyxl`。
- 可选验证工具 `verify_formulas.py` 需要额外安装 `formulas` 库（`pip install formulas`）。

### Step 2 运行核心恢复脚本
```
python scripts/restore_links.py <明细表.xlsx> [输出目录]
```
脚本自动完成：
1. 分析全部 sheet 结构（叶子表/二级汇总/分类汇总/2-分类汇总/1-汇总表，按名称与编号规律识别）；
2. 恢复**原始隐藏状态**：链接可写入隐藏表，但交付文件中原隐藏表保持隐藏；
3. 重建四层链接（明细表合计→二级汇总→分类汇总表→2-分类汇总→1-汇总表 ÷10000 万元换算），
   增值额 `=E-D`、增值率 `=IF(D=0,"",F/D*100)`；
4. 逐链接对比"计算值 vs 原静态值"（金额容差 ±0.01 元、比率 ±0.01 个百分点）；
5. 叶子表"明细行合计 vs 表内合计行"自洽验证（毛合计与净合计）；
6. 生成《<文件名>_链接恢复.xlsx》与《<文件名>_链接恢复对比报告.xlsx》。

### Step 3 复核验证（推荐）
```
python scripts/verify_formulas.py <输出文件.xlsx> <原文件.xlsx>
```
用 formulas 引擎对输出文件整体重算，与原始缓存值逐格比对。
注意：`formulas` 库不支持 `SUBTOTAL`（`4-8固定资产汇总` 相关行报 #NAME? 属引擎限制，
非文件错误，Excel/WPS 中正常），这类单元格以 Step 2 的人工核验为准。

### Step 4 交付说明
- 交付主文件在 Excel/WPS 中打开即自动计算（openpyxl 写入的公式无缓存值，首次打开需启用计算）。
- 报告"不一致"条目 = 原静态值无法由底层明细重新汇总得到，需人工核实该科目原始数据。
- `00000000` 表为旧版 Excel 宏病毒残留文本页（1998 XF.Classic），保持隐藏并建议删除。

## 表结构要点

详细结构规律与坑位清单见 `references/structure.md`，执行前建议通读。核心要点：
- 四层链条：`叶子表合计 → 二级汇总(名含"汇总") → 分类汇总表(3/4/5/6-xx汇总) → 2-分类汇总 → 1-汇总表(÷10000)`。
- **科目表数据条数不确定 → 合计行按内容动态定位（A 列含"合计"的最后一行），绝不依赖固定行号**；
  汇总表位置相对固定，但同样按内容检测以兼容微调。脚本已对 10~309 行不等及插入行后的表验证通过。
- **合并三列结构自动识别**：`3-9-x` 存货系列等表的"账面价值/评估价值"为合并单元格
  （数量/单价/金额 三列），脚本自动用 R6 子表头"金额"列取数（如原材料取 G/J 列），
  单列金额结构表不受影响；特殊表可在 `LEAF_COL_OVERRIDE` 显式指定。
- **净资产为负时增值率取绝对值**：增值率公式用 `ABS()` 分母，账面净资产为负（资不抵债）时
  增值率与原系统一致显示正值，正常科目不受影响。
- **原模板留空的列保持留空**：原静态值为空的列不写入公式（如 `4-8-7固定资产清理` 无账面原值/
  评估原值概念，D/F 列留空，仅恢复净值列 E/G）。
- 合计行 A 列"合计"字样有全角空格，匹配前先去空格；减值结构取最后一个合计行（净值）。
- 固定资产/投资性房地产/在建设备/生物资产/油气资产为原值/净值多列结构，**向上汇总取净值列**。
- 数据行识别用编号正则，勿假设固定起始行（`3-2交易性金融资产汇总`、`3-9存货汇总` 数据从 R6 开始）。
- 源公式无缓存值时，对比结果标记"源无缓存值（以 Excel 实算为准）"，不误报不一致。
- 已存在的公式（`4-8固定资产汇总` 链接、SUBTOTAL 小计、`1-汇总表` D34/E34 勾稽校验）一律不动。

## 个性化调整点（scripts/restore_links.py 顶部常量）

| 常量 | 作用 |
|---|---|
| `LEAF_COL_OVERRIDE` | 原值/净值双列叶子表的账面/评估列映射（按表名），新模板列结构变化时按需增改 |
| `CAT_CHILD_COL_OVERRIDE` | 分类汇总取净值列的二级汇总（如 `4-8固定资产汇总` → E/G） |
| `AMOUNT_TOL` / `RATE_TOL` | 金额、比率对比容差 |
| `CATS` / `SUM2` | 分类汇总表/二级汇总表清单（sheet 命名不同时按需增改） |

## Resources

- `scripts/restore_links.py`：核心恢复脚本（恢复隐藏保持 + 四层链接重建 + 对比验证 + 报告生成）
- `scripts/verify_formulas.py`：formulas 引擎整体重算比对（可选，需 `pip install formulas`）
- `references/structure.md`：模板表结构规律、特殊列结构、坑位清单
