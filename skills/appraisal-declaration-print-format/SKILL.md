# 评估申报表打印格式

中文触发词：申报表打印格式设置。

## 使用流程

运行内置脚本：

```bash
python3 scripts/adjust_appraisal_declaration_print.py "/path/to/申报表.xlsx"
```

脚本会先执行申报表专用转换，再复用同一 Skill 运行包中的 `appraisal-detail-print-format` 打印格式能力。

## 申报表规则

- 隐藏所有名称包含 `汇总` 的 sheet；原本隐藏的明细 sheet 不主动取消隐藏。
- 对可见明细表，隐藏以下申报表不需要的列：
  - `评估价值`
  - `增值额`
  - `增值率` / `增值率%` / `增值率％`
- 如果目标表头是多列表头或合并单元格，隐藏完整的合并列范围。
- 对存货、固定资产、投资性房地产、房屋建筑物、构筑物、机器设备、车辆、电子设备、在建工程、土地等实物资产/非流动资产明细表，统一适用多列表头隐藏规则。
- 清除奇偶页和首页页脚右侧的评估人员内容。
- 打印区域水平居中，并保持左右页边距一致，使两侧对齐。
- 预留较大的底部安全区域，避免表格压到填表人/日期落款。
- 将可见 sheet 标题里的 `评估明细表` 替换为 `评估申报明细表`。
- 清理只有序号、没有对象、没有非零金额的模板空行；序号本身和零金额都不算实质内容。
- 模板空行清理后，如果整张明细表没有对象或金额，隐藏该 sheet。
- 如果整本 workbook 没有任何可保留的实质明细 sheet，不能保存成“所有 sheet 都隐藏”的状态；应恢复原 sheet 显示状态并输出 `no_visible_detail=True`。若原文件本身所有 sheet 都隐藏，则仅将“设定信息”或首个 sheet 设为可见，保证工作簿合法，不改业务数据。
- 表格主体行高默认统一为 `16.5`。
- 清理后自动做打印分页判断：
  - 短表：在最后一个实质数据行下方插入带格式的整行空白行，尽量填满当前页且不新增空白页；
  - 长表先删除最后一个实质数据行与第一行合计之间的模板空行，再按每页可容纳总高判断；
  - 长表且最后打印页仍有较多实质数据：在最后一个实质数据行下方插入带格式的整行空白行，填充最后一页；
  - 长表如果最后打印页实质数据很少、空白比例很高，或最后页只有空白行和/或合计区：优先删除合计上方模板空行，再小幅压缩主体行高，把合计区并回上一页或避免无效页；
  - 长表插行试算时必须把合计/减值准备/最终合计作为一个整体预留，不能把合计块拆到下一页。
- 分页判断必须计入 `print_title_rows` 里的重复标题行。当前导出表通常为 `$1:$6`，包含标题、基准日、表号/单位、双表头。
- 因 WPS 打印预览会额外占用页脚和落款安全区，脚本内部用保守页高判断：短表按约 `95%` 可用页高，长表按约 `93%` 可用页高试算，避免最后一行合计或合计块被挤到下一页。
- 不移动、不重建、不重写合计区。插入/删除必须发生在最后一个实质数据行下方、第一行合计/汇总行上方，让公式随整行结构自然调整。
- 脚本会输出自动打印状态体检结果，例如 `pages`、`audit_issues:last-page-no-detail`、`summary-or-blank-only-page`、`visible-width-low`。
- 保留工作簿原有数值、公式、页脚左侧内容、sheet 顺序和原本隐藏状态。

## 打印规则

申报表转换后，继续应用基础明细表打印规则：

- A4 横向打印；
- 所有可见列打印在一页宽度内，不使用固定百分比缩放；
- 隐藏显示为空的列，以及币种全部为人民币时的汇率列；
- 隐藏空的成新率列；
- 打印区域收紧到实际表格边界；
- 统一可见列宽和左右页边距；
- 清除手工分页符，并保留页脚安全距离。

申报表默认使用 `0.70` inch 左右页边距、`0.85` inch 下页边距、`0.45` inch 页脚位置。只有为避免空白页或合计区单独成页时，才允许小幅压缩行高。

## 常用参数

```bash
# 只预览处理结果，不写入文件
python3 scripts/adjust_appraisal_declaration_print.py "/path/to/明细表.xlsx" --dry-run

# 明确要求不生成备份时使用
python3 scripts/adjust_appraisal_declaration_print.py "/path/to/明细表.xlsx" --no-backup

# 覆盖默认页宽/页边距
python3 scripts/adjust_appraisal_declaration_print.py "/path/to/明细表.xlsx" --target-width 143 --margin 0.45
```

检查文件完整性：

```bash
unzip -t "/path/to/明细表.xlsx" | tail -5
```
