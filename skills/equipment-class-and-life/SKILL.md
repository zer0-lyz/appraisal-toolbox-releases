# 设备分类与年限判定（equipment-class-and-life）

按"两份评估参数资料 + 网络查询"补充设备清单的分类、大类、经济耐用年限、区间与来源，并保证同种设备口径一致。本技能沉淀自多批次实操（3506 行化工厂 / 209 行电池厂 / 57 行应急抢险基地），其中的**分类-年限口径表**与**来源标注惯例**为跨批次一致性基准，沿用优先、改动需有据并回写本表。

## 适用环境与工具约定

- Python 一律用 `D:\Anaconda3\python.exe`（用户硬性规定，勿用托管版/裸 `python`）。
- 读取 .xlsx 用 openpyxl；读取旧 .xls 用 xlrd（`D:\Anaconda3` 已装）；报告用 python-docx（已装 1.2.0）。
- 网络查询走多引擎聚合搜索技能（multi-search-plus），关键词检索"折旧年限/经济寿命/耐用年限+设备名"。
- 交付物：更新后的工作簿 + Word 版《…补充说明与一致性校验报告.docx》（保存在工作区/桌面）；修改前先做带时间戳备份。

## 工作流

### 第 1 步 摸清工作簿现状
1. 列 sheet 名与行列数；注意表名实测为「AI设备分类与年限」，列序固定为 7 列（见 description）。
2. 全量导出各行「序号|设备名称|…待填列」；记录待填行数、已有空值列。
3. 先备份：`shutil.copy2(原文件, 原文件前缀_备份YYYYMMDD_HHMMSS.xlsx)`。

### 第 2 步 引用参考依据（已固化，勿重新提取源文档）
两份参考依据已**全文固化**到本技能 references/，直接按设备关键词检索引用，不再打开源文件解析：
- `references/table-2012.md`：《常用评估参数2012v1（初稿）》「设备参考年限、安装费率」sheet 全部 620 行提取（序号|设备名|年限下限|上限|建议使用年限|安装费率|备注）。区间=使用年限范围，年限优先取"建议使用年限"。
- `references/table-2024.md`：《资产评估报告编写模块常用语参考（2024版）》三张年限表**已人工核对净表**（表一全量、编号折旧年限表 19-22 类别、表二本项目锚点）+ 来源定位速记。
- `references/2024-tables-raw.txt`：2024 版年限表原文区段备份（含源 txt 行号，OCR 三栏交错，名称与紧邻数值行配对），仅当净表缺条目时查此处。
仅当用户提供了**新版/更新版**参考文件时才需重新提取；新条目按"名称→紧邻数值行"配对并回写净表。

### 第 2.5 步（优先分支）既有口径回填——已有认可底稿时不要重新判定
若本批次客户已有填好分类的底稿/清单（如《…固定资产设备底稿-Vn》「设备计算表」），
**先做同源判定，再决定是"回填"还是"重判"**：
1. **查外部链接**：`python -c "import zipfile;print([n for n in zipfile.ZipFile(p).namelist() if 'externalLink' in n])"`
   → 若 `externalLink1.xml.rels` 的 Target 指向该底稿，说明两文件同源，**回填**优先。
2. **按设备编号一对一核对**（不行时退化为"名称+规格型号"），要求交集=100%；
   同时用"名称→分类"映射做**第二口径互校**，两口径不一致的行必须逐条列出。
3. **复核底稿口径本身**：底稿也会有错（见 values.md 九·9.3 的"一体机/主机/HF"撞词坑）。
   发现同族设备被拆到两个分类的，按"同种设备口径必须一致"归并，并把修正行**单独出表**交用户，
   同时建议回改底稿，保持两文件长期一致。
4. **写入通道**：含外部链接/公式的文件**一律走 WPS COM（`KET.Application`）**，
   不得用 openpyxl 保存（会丢缓存值与外部链接）。写完逐格回读校验 + 校验公式缓存值未被破坏。
   详见技能 `wps-native-xlsx-edit`。

### 第 3 步 分类判定（核心规则）
1. **大类只能取 8 个选项，严禁自造**：家具；文教、工美、体育和娱乐用品；塑料制品；通用设备；专用设备；电气机械及器材；通信设备、计算机及其他电子设备；仪器仪表。
2. **异名同物先合并**：设备名去掉括号内资产编号/品牌后归基名，再套同义词映射（常见对照见 references/values.md）。例：班台=大班桌=大班台；桁车=行车=桥式起重机；沥青混凝土搅拌机=自动混合料拌合机；电子汽车衡=地磅；门禁设备=人员通道设备（出入口控制系统）；1+1+3沙发=沙发。
3. **同种设备年限必须一致**：同一基名（含同义词合并后）的所有行，分类/年限/区间必须完全相同；同组同类别内不同种设备可共用口径（如全部厨房设备 8 年）。
4. 套用既定分类-年限口径表（references/values.md）取 分类/大类/年限/区间/来源；表中没有的设备，按最近类别关键词匹配，数值以参考表原文条目或网络查询为据，并把新口径回写到 values.md。

### 第 4 步 取值与来源标注
- 年限取整年；**年限必须落在"区间"范围内**（区间格式 `低-高`，如 8-12）。
- 来源标签（沿用先例写法，直接写全称到单元格）：
  - A = 《常用评估参数2012v1（初稿）》设备参考年限表
  - B = 《资产评估报告编写模块常用语参考（2024版）》机器设备经济寿命参考年限表
  - C = 网络查询：《通用与专用设备经济寿命参考年限表》
  - D = 网络查询及行业惯例
  - E = 网络查询：《GB/T 7723-2017》电子汽车衡耐用年限10-15年
- 引用**真实存在**的条目；参考表无对应条目的类别（如"家具"两表均无专条）不得硬标 A/B，应标 D 并在报告注明"无专条、按惯例"。已在 values.md 标注的历史坑位必须规避。

### 第 5 步 回填与自检
1. openpyxl 写入 C–G 列；E 列存整数。
2. 运行 `scripts/verify_fill.py <工作簿路径>` 自动自检：
   - 空值行=0；大类在白名单内；区间格式 `d-d` 且不倒挂；年限∈区间；同种（基名+同义词映射）组内口径一致。
3. 全部通过后保存。

### 第 6 步 出具报告（Word，python-docx）
固定七节结构：
1. 任务完成概况（填列率、大类使用分布）
2. 分类与年限口径汇总表（分类/大类/台数/年限/区间/来源依据）
3. 异名同物识别与合并口径
4. 同种设备一致性校验（分组表+结论）
5. 主要依据（源文件原文条目 + 网络查询要点）
6. 特殊事项与复核提示（把拿不准的归属列出来请用户裁量）
7. 跨批次口径比对（如有已认可历史输出，如 _result_preview.tsv）

### 第 7 步 跨批次比对（如有历史已认可输出）
以历史已认可输出（非原始清单）为基准，按基名比对重叠设备的 分类/大类/年限/区间，必须 0 差异；有差异须逐项说明原因（口径修正要有依据）。

### 第 8 步 收尾
- 追加当日工作日志 `.workbuddy/memory/YYYY-MM-DD.md`；口径/坑位修订同步回写本技能 references/values.md。

## 已知坑位与复核提示（高发，务必执行）
1. 不动产/场站类条目（如"XX应急基地"、各"XX气化站"）→ 暂按 建（构）筑物及其他 20 年/15-30 年、大类"专用设备"（承先例），报告提示"应按资产明细拆分（储罐/气化器/调压计量/站房等）"。
2. 劳动防护用品（低温防护服/工服/手套等）→ 8 个大类**无对应项**（纺织服装），暂按"通用设备"兜底、3 年/3-5 年（D）填列，报告须提示"建议按低值易耗品/费用化处理或单列，请确认"。同种多件（如各站配备的防护服）按 防护服 后缀归组保证口径一致。
2. 电动门/伸缩门/圈门/大门 → 建（构）筑物及其他 20 年/15-30 年；若账面按设备核算（有设备编号）提示可改"其他设备-通用设备"12 年/10-14 年，请用户结合科目确认。
3. 油烟净化器：可归 厨房设备(8 年/8-12) 或 环保设备(12 年/10-16)，二选一必须说明并提示可改。
4. 电子汽车衡：按 E（GB/T 7723-2017，10-15 年），勿沿用早期 8-12 年区间。
5. 空调设备 12 年/8-14 年为类别综合口径（分体/柜式 4-8、中央 8-15 综合），沿用先例，报告注明。
6. 厨房设备大类统一"电气机械及器材"（含不锈钢保温台/碗碟柜等，可另注可归通用设备）。
7. 非年份数字输出加千分位（报告统计数字）。
