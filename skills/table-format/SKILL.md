# 表格设置

用于批量统一 `.docx` 文档中全部表格的格式。脚本只处理本地副本，调用方负责在成功后替换原文件或写入新的目标文件夹。

## 预设

- 中文文本使用宋体，英文和数字使用 Times New Roman
- 字号 10 磅
- 表格按窗口宽度自适应
- 所有单元格内容垂直居中，表格段落统一单倍行距
- 行高最小值 0.6 厘米
- 自动识别一行或两行表头并重复，排除表格前的资料字段行
- 表头加粗，水平和垂直居中
- 自动识别“序号/序/项次”列，按最长内容自动收窄列宽，序号水平和垂直居中
- 自动识别“编号/编码/代码/证号”等标识列，按最长编号自动计算列宽并保持完整显示
- 数字单元格强制右对齐，清理原有两端/分散对齐属性；保持 10 磅字号和数字原始比例，不使用横向缩放，列宽优先按内容分配，文字单元格左对齐
- “备注/说明”列中的 `-`、`0.00` 等占位值自动清空，其他数据不清理
- 上下边线 1.5 磅
- 内部横线和竖线 0.5 磅
- 左右边线取消
- 保留原有横向和纵向合并单元格结构

## 调用

```text
python3 scripts/format_word_tables.py /absolute/path/document.docx
```

脚本以 JSON Lines 输出处理阶段，不输出文档正文或其他敏感信息。`.doc` 和需要保留宏的 `.docm` 暂不在本模块支持范围内。
